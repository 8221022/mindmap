# 考公思维导图

交互式考公知识点思维导图:识别特征 → 方法 → 口诀 → 易错点。

- **点击带 📖 的节点**:弹出该考点的详细讲解(概念、步骤、口诀、易错点、例题图解)
- **展开/折叠节点**:视图自动缩放适配
- **顶部搜索框**:高亮考点
- 完全离线可用,手机浏览器也能打开
